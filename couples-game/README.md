# Couples Game 🔥

A real-time couples challenge and reward game with Firebase sync and Vercel hosting.

## Features

- 🔄 Real-time sync between both phones via Firebase
- 💋 4 intensity levels with custom challenges
- 🏆 Daily challenges throughout the day
- 🎁 Night rewards based on performance (tap to reveal)
- 📱 Works on both iOS and Android
- 🔐 Private - only you and your partner can access

## Setup

```bash
cd couples-game
npm install
npm start        # local dev at http://localhost:3000
npm run build    # production build in build/
```

## Deploy to Vercel

1. Push this repo to GitHub.
2. On Vercel: **New Project → import this repo**.
3. Set the **Root Directory** to `couples-game`.
4. Framework preset: **Create React App**. Build command `npm run build`, output `build`.
5. Deploy, then both partners open the same URL on their phones.

## Technologies

- **React** - UI framework
- **Firebase Firestore** - Real-time database
- **Vercel** - Hosting
- **GitHub** - Version control
